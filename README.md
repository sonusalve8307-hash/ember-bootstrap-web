# EMBER — Premium Coffee Website

EMBER is a modern, premium coffee-shop website built using **HTML, CSS, and Bootstrap 5**.

The website focuses on a warm editorial design, responsive layouts, interactive components, premium typography, and a clean café experience across desktop and mobile devices.

---

## ☕ About EMBER

EMBER is designed as a fictional premium café and coffee brand.

The website provides visitors with:

* A visually engaging homepage
* Coffee and food categories
* A complete menu page
* Signature coffee selections
* Special offers
* Café story section
* Visit information
* Table reservation CTA
* Social media gallery
* Responsive navigation

The design combines a warm cream background with deep teal and copper-orange accents to create a premium coffee-house aesthetic.

---

## ✨ Features

### 🏠 Homepage

* Responsive Bootstrap navbar
* Hero section with coffee imagery
* Explore categories
* Our Story section
* Signature Picks
* Special Offers
* Visit EMBER section
* Reservation CTA
* Social Gallery
* Footer

### 📖 Menu

Dedicated menu page containing:

* Coffee
* Cold Drinks
* Breakfast
* Desserts

Menu categories are implemented using **Bootstrap navigation pills**.

Each menu item includes:

* Product image
* Product name
* Description
* Price
* Add button
* Hover interaction

### 📱 Responsive Design

The website is designed to work across:

* Desktop
* Laptop
* Tablet
* Mobile

Bootstrap's responsive grid and utility classes are combined with custom CSS for precise visual styling.
